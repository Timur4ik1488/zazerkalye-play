## Сводка по миру (из роликов, высокая уверенность)

- **Визуал:** намеренный PS1 / «слишком по-старинке», иногда мета-шутка «Зазеркалье для PS1 (демо)».
- **Тон:** абсурд + weirdcore + тёмная комедия; **не** чистый хоррор — странно, смешно, иногда жутковато, но «игрово».
- **Экономика:** **кукичи** (огрызки яблок) — валюта и стройматериал дядюшки Фантасмагора.
- **Бой/действие:** Сатор Арепыч **кокает/колупает бобылей**; мелких можно бить, крупных препятствий — обходить/перепрыгивать.
- **Коллекция:** выбор бобыля из ростера (Чёрный Экллер, Ёксель-Моксель, Вандух, …).
- **Мета:** «Вершитель судеб» — голосование/выбор следующего события (идеально под сезонные апдейты).
- **День/ночь:** Пацаноиды сильны днём (под патронажем ОНО/солнца); ночью Гремучее древо опаснее.

## Ключевые персонажи для беты (must)

1. **Сатор Арепыч** — playable  
2. **Бобыли** (обычный / крепкий) — цели кокалки  
3. **Пацаноиды** — осколки / равновесие  
4. **Дядюшка Фантасмагор** — хаб / цирк / награды  
5. **ОНО (Орбитальный непревзойдённый объект)** — таймер / давление  
6. **Кожник** — секретный chase в хлеве  
7. **Казимир** — секретный вор ложек  
8. **Вершитель судеб** — постматч «что дальше» (UI)

## Что это меняет в бете (решения)

| Было (до видео) | Стало после видео |
|---|---|
| Общий «сюрреализм» | Конкретные мемы: кукичи, кокалка, бобыли, ОНО, хлев |
| Случайный бестиарий | Ростер имён из роликов |
| Только роща | Роща = MVP; следующие зоны: цирк Фантасмагора, Сладкий хлев, «на дне» |
| Просто лидерборд | + «Вершитель судеб» как weekly vote / random event |
