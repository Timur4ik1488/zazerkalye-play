# ЗАЗЕРКАЛЬЕ — Итоговое заключение для бета-релиза в Яндекс Играх

**Версия:** 1.0  
**Дата:** 12 сентября 2026  
**Формат бета (зафиксирован командой):** вариант **B** — короткие сессии 2–5 минут  
**Стиль (зафиксирован командой):** сюрреализм, ретро PS1 / Dendy / «кассеты», не мрачный хоррор  
**Материалы:** постер персонажей + 2 GDD-документа команды + публичный лор @zazer_kalye  
**Видеофайлы:** ещё не загружены — выводы по канону помечены уровнем уверенности и будут уточнены

---

## 0. Согласованные решения (чтобы разработка не разъехалась)

| Вопрос | Решение для беты | Почему |
|---|---|---|
| Жанр | **Surreal session adventure**: хаб + короткие PvE-сессии + коллекция | Совмещает выбранный вами **вариант B** и рекомендацию GDD «adventure + мини-игры + коллекция» |
| Онлайн | Нет realtime PvP | Сложность серверов, токсичность, отзывы на Brawl Stars; для Яндекс Игр в MVP хватает лидербордов |
| Движок | **Vite + TypeScript + Phaser 3** (+ CRT/PS1-фильтр) | Быстрый HTML5-билд под Яндекс Игры; Unity+WebGL — следующий этап, если нужен настоящий 3D |
| Возраст | Цель **6+ / 12+** после модерации; тон «странный, но игровой» | Постер 18+ относится к вечеринке клуба, не к игре |
| Монетизация | Interstitial только после матча; Rewarded — добровольный бонус | Требования Яндекс Игр 4.x; детская аудитория |
| Scope беты | 1 хаб-меню, **1 играбельная зона**, 1–2 режима сессии, 8–12 сущностей, коллекция кукичей/карточек | «Лучше маленькая цельная игра, чем 15 недоделок» (ваш GDD) |

**Что сознательно отложено:** полный 3D open world, MMO, сложный бой, торговля игроков, 200 локаций «как в роликах».

## 1. Видение игры

### 1.1. Одним предложением
Игрок на 2–5 минут проваливается в **Зазеркалье**: ходит по странному ретро-миру, **кокает бобылей**, собирает **кукичи**, встречает абсурдных NPC и пытается восстановить **пацаноидное равновесие** — потом получает награду и хочет «ещё один заход».

### 1.2. Что это НЕ
- Не хоррор с джампами.
- Не клон Brawl Stars / Stumble Guys.
- Не музей роликов.
- Не гиперреалистичный RPG.

### 1.3. Эмоциональный контракт
Ребёнок/подросток должен чувствовать: «мир странный, но безопасный и смешной; за углом всегда что-то нелепое; я хочу найти ещё одного персонажа».

### 1.4. Позиционирование в сторе
**«Зазеркалье»** — короткие сюрреалистические вылазки в мемную вселенную. Ретро-3D вайб, коллекция существ, сессии «ещё разок».

## 2. Анализ материалов

### 2.1. Постер (высокая уверенность по визуалу)
Визуальный язык подтверждает: низкополигональность / uncanny faces / тёмный лес-сцена / кукичи как визуальный якорь экономики / ансамбль персонажей важнее декораций.

### 2.2. GDD-документы команды (высокая уверенность по продукту)
Ключевые выводы документов, с которыми согласен и которые беру в бету:

1. Сила IP — **персонажи и абсурд**, не «прыжки».
2. Формула: исследование + короткие цели + мини-игры + коллекция + секреты.
3. Каждые 1–3 минуты — маленькое «ого».
4. Не раздувать: 1 хаб, 3 зоны (для полной беты), 5 мини-игр, 40–60 коллекций.
5. Яндекс Игры любят быстрый старт и короткие сессии.
6. Из отзывов конкурентов: бесить игроков рекламой mid-match / paywall / лагами — смерть retention.

**Где я корректирую документы:** полный Unity 3D sandbox для *первой* HTML5-беты — слишком тяжёлый. Делаем вертикальный срез на Phaser с той же петлёй; 3D Unity — post-beta, если конверсия окупит.

### 2.3. Публичный лор (средняя–высокая уверенность)
Источник: обзоры Афиша Daily / 2×2 / Life.ru по @zazer_kalye. Не объявляем это «официальным каноном автора без сверки», но используем как рабочую библию до разбора ваших 200 роликов.

Странный документальный закадровый стиль роликов → в игре: короткие подписи и абсурдные реплики (1–2 строки), без длинных диалогов.

## 3. Планируемые локации

### 3.1. Бета (must)
1. **Центральное Зазеркалье (хаб-меню)** — выбор героя/режима, бестиарий, награды.
2. **Сумеречная роща** — основная сессия: бобыли, кукичи, пацаноидные осколки, туман, пни, дупла.
3. **Зеркальная версия рощи** (секрет внутри матча) — альтернативная расстановка, 1 редкий персонаж.

### 3.2. Сразу после беты (should)
4. **Цирк Фантасмагора** — серия аркадных мини-игр 30–90 сек.
5. **Деревня домиков** — короткие поручения NPC.
6. **Медный Град** — «отчёты на завтрак» как шуточная экономика.

### 3.3. Позже (could)
7. Подземелье труб / щекоточный клуб (без токсичности, как абсурдный лабиринт).  
8. Запретная пустыня / караваны Птозного Эдгара.  
9. Подводное Зазеркалье (Улитолий).  
10. Скрытая зона эндгейма.

### 3.4. Варианты решений по локациям
- **A (выбрано):** 1 зона глубоко проработана.  
- **B:** 3 зоны тонким слоем — риск «пустоты».  
- **C:** процедурный лес без уникальных NPC — убивает IP.

## 5. Механики

### 5.1. Core loop (вариант B, согласован)

```
Меню/хаб → старт сессии 150–180 сек → роща
  → кокать бобылей / собирать кукичи / искать осколки пацаноида
  → (опц.) зеркальная дверь / секрет
→ итог: очки, кукичи, карточки бестиария
→ interstitial (пауза) / rewarded бонус ×2
→ снова в хаб
```

### 5.2. Must-have
- Мгновенный старт (<30 сек до действия).
- One-thumb управление (джойстик + кнопка «Кокнуть»).
- Цель матча на экране всегда.
- Коллекция/бестиарий (хотя бы 12 карточек).
- Сохранение прогресса (local + YaGames Player Data).
- Секрет (зеркало / глаз).

### 5.3. Nice-to-have (после вертикального среза)
- 2-й режим: цирковая волна.
- Еженедельное испытание.
- Косметика шляп/кокалок.
- NPC «помнит» игрока.

### 5.4. Cut из беты
- Realtime multiplayer, чат, торговля, сложный крафт, 10 валют, длинный сюжет.

### 5.5. Мини-игры (бэклог из вашего GDD, приоритет)
1. Кокалка бобылей (основной матч) — **в бете**.  
2. Найди глаз — **секрет в бете**.  
3. Доставка странного предмета.  
4. Зеркальный лабиринт.  
5. Поймай существо.  
6. Комната с секретом.

## 6. Конкурентный анализ и отзывы

### 6.1. Что дети реально «залипают» (синтез)

| Источник | Механика-хит | Урок для Зазеркалья |
|---|---|---|
| **Brawl Stars** | Матч 2–5 мин, яркие герои, «ещё раунд» | Ритм сессий; **не** копировать lootbox/чат |
| **Roblox: Brookhaven** | Свобода роли, социальный вайб | Лёгкий хаб и ощущение «мира» без MMO |
| **Roblox: Adopt Me / Grow a Garden** | Коллекция + редкости | Бестиарий существ Зазеркалья |
| **Roblox: Tower of Hell** | Короткий skill-loop | Повторяемые мини-игры |
| **Яндекс Игры kids/casual** | Мгновенный старт, one-thumb | Обязательный mobile-first |
| **Subway Surfers** | Простой ввод, монеты, runner | Понятная награда за забег |
| **Stumble Guys** | Короткие раунды, без чата | Безопасный соцслой; избегать P2W emotes |

### 6.2. Боли из отзывов (чего избегать)
- Агрессивная реклама во время управления.
- Paywall на базовый прогресс.
- Непонятно «что делать» в первую минуту.
- Лаги WebGL / нестабильный FPS.
- Однообразие без новых «ого».
- Токсичный чат / незнакомцы (для детской аудитории — не делать).

### 6.3. Что взять у конкурентов этично
Короткая петля, коллекция, секреты для Shorts, косметика без силы, события недели.

## 7. Насколько «стрельнет» и что поменять, чтобы точно зашло

### 7.1. Оценка потенциала (как в вашем GDD, уточнённая)

| Вариант | Оценка |
|---|---|
| Музей роликов | 4–5/10 |
| Чистый платформер | 6/10 |
| Только квест | 6.5/10 |
| **Сессии B + коллекция + секреты + сильный ретро-стиль (наш путь)** | **8.5–9/10 потенциала соответствия рынку** |

Это не прогноз установок. Это соответствие паттернам удержания.

### 7.2. Что обязательно, чтобы «стрельнуло»
1. **Узнаваемые мемы вселенной в первые 10 секунд** (кукичи, бобыли, пацаноид, закадровый тон).  
2. **Смешной fail/win экран**, который хочется заскриншотить.  
3. **Бестиарий с ???** — «собрал 4/12».  
4. **Секретные события** раз в несколько матчей.  
5. **Стабильный mobile FPS** важнее красивых эффектов.  
6. Обновление контента раз в 1–2 недели после релиза (1 персонаж / 1 секрет).

### 7.3. Риски провала
- Сделать слишком страшно → отток младших и родителей.  
- Сделать generic runner без лора → потеря IP.  
- Раздуть 3D open world до релиза → не выйти.  
- Запереть прогресс за рекламой → жалобы и модерация.

## 8. Яндекс Игры: требования и модерация

- Встроить SDK (`YaGames.init`), вызвать `LoadingAPI.ready()` когда можно играть.
- Реклама только через SDK; interstitial в логических паузах; rewarded добровольно и как бонус.
- Пауза звука и геймплея на время рекламы.
- Гость-вход / сохранение прогресса.
- ZIP до лимита платформы, `index.html` в корне.
- Возрастной тег соответствует содержанию (избегать крови, реалистичного насилия, азартных лутбоксов).

## 9. Техстек и архитектура беты

```
Vite + TS
 └─ Phaser 3 scenes: Boot → Preload → Menu → Match → Results
 └─ systems: Input, Spawner, Collection, Score, Save
 └─ yandex/: sdk.ts (real + mock)
 └─ CRT/PS1 post-FX overlay (CSS + canvas dither)
```

**Почему не Unity прямо сейчас:** быстрее итерации HTML5, проще CI в текущем окружении, тот же game loop переносится в Unity позже 1:1.

## 14. Первый час игрока (сценарий беты)

1. Заставка / меню «ЗАЗЕРКАЛЬЕ» (≤5 сек до кнопки).
2. Игрок жмёт «Войти в Сумеречную рощу».
3. Подсказка Поленыча: цель = 3 осколка пацаноида, кокалка на пробел/кнопку.
4. Первый бобыль за 20–40 секунд → +кукич → «ого».
5. Встреча Акакия → реплика → карточка бестиария.
6. Сбор 1–2 осколков / секретного глаза.
7. На 30 сек до конца ОНО «смотрит» (flash) — напряжение без хоррора.
8. Победа (3/3) или тайм-аут → экран итога со смешной формулировкой.
9. Rewarded ×2 (добровольно) → interstitial → хаб.
10. Игрок открывает бестиарий и видит «???» → желание ещё раунда.

## 19. Обновление v1.1 — разбор Яндекс Диска (22 уникальных ролика)

### Подтверждено роликами
- Бренд и тон совпадают с постером: PS1-сюрреализм, абсурд, мемные имена.
